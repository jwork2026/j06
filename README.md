# J06：并行优化、录制回放与网络联机

本项目提供一个躲避游戏示例，演示如何为游戏增加多线程并行优化、录制回放和网络联机能力。

## 示例代码

### 多线程并行优化

使用 `ExecutorService` 线程池，将物理更新和 AI 避障计算分批交给多个线程处理，等待任务完成后再继续后续更新和渲染。支持串行与并行模式切换，并提供性能对比程序。

参考：`core/PhysicsSystem.java`、`core/GameLogic.java`、`example/ParallelBenchmark.java`。

### 录制回放

通过独立线程将关键帧和输入事件写入 JSONL 文件。回放时读取记录，按实体 ID 恢复对象及外观，并在关键帧之间插值，使运动连续。存储接口与录制逻辑分离，便于扩展存储方式。

参考：`recording/`、`example/ReplayScene.java`。

### 网络联机

使用 Java NIO 实现基于 `Selector` 的服务端，接收客户端输入并广播游戏状态。服务端统一计算玩家和 AI 的状态，客户端通过缓冲和插值显示远程场景。实现了 TCP 消息分帧、部分写入和断线清理。

示例支持主机玩家和一个客户端玩家在同一场景中移动，其他连接可观察状态。目前只有主机玩家碰到 AI 会触发游戏结束，完整多人胜负规则需要进一步完善。

参考：`net/`、`example/GameScene.java`、`example/ClientLauncher.java`。

## 作业要求

请参考示例，在你自己的游戏中实现类似能力：

1. **并行优化**：分析计算瓶颈，使用线程池并行处理适合拆分的任务，保证线程安全，并测试、比较串行与并行的性能。
2. **录制回放**：设计记录格式和存储接口，保存游戏过程，实现状态恢复与回放，确保实体增删、外观和运动能够正确呈现。
3. **网络联机**：支持至少两个玩家参与同一局游戏，明确交互与胜负规则，实现输入传输、状态同步和断线处理，并测试多连接下的性能。

提交游戏代码与运行说明，在 README 中说明设计、线程安全处理、测试结果和已知限制。录制包含上述三项功能的演示视频，上传小破站并提供链接。

**关键代码应手工编写，并能够解释其实现原理，考试会涉及这些内容。**

## 运行示例

需要 JDK 11 或更高版本，以及支持 OpenGL 的桌面环境。首次运行先下载 LWJGL 依赖：

```bash
./download_lwjgl.sh
./run.sh                         # 主机：在菜单中选择 START GAME，自动录制
./run_client.sh 127.0.0.1         # 另一终端启动客户端，远程联机时替换 IP
./run_replay.sh                  # 回放最新记录，也可通过主菜单选择记录
```

使用 WASD 或方向键移动。记录文件保存在 `recordings/` 中。

```bash
GAME_PARALLEL=false ./run.sh     # 串行模式
GAME_PARALLEL=true ./run.sh      # 并行模式
./run.sh benchmark 500 300       # 500 个对象、300 步的计算性能对照
./test.sh                       # 无窗口集成检查
```

Windows 使用 `download_lwjgl.bat`、`run.bat` 和 `run_client.bat`。示例使用 LWJGL/OpenGL，你可以继续使用自己的渲染方式。
